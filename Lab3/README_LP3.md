## 1. Требования к практической работе

* **Условие задачи (Вариант 8):** Найти экстремумы функции:
  $$f(x, y, z) = 2x - y + 2z$$
  при условии:
  $$x^2 + y^2 + z^2 = 9$$

## 2. Ход решения вручную

1. **Определение нерегулярных точек:**
   
   * Рассмотрим градиент функции ограничения $\nabla g = (2x, 2y, 2z) = (0,0,0) \implies (0,0,0)$.
   * Подставим точку $(0,0,0)$ в уравнение ограничения: $0^2 + 0^2 + 0^2 = 0 \neq 9$. Точка не принадлежит области ограничений $\implies$ **нерегулярных точек нет**.

2. **Составление функции Лагранжа:**
   $$L(x, y, z, \lambda) = 2x - y + 2z + \lambda(x^2 + y^2 + z^2 - 9)$$

3. **Вычисление частных производных и составление системы уравнений:**
   $$\begin{cases}
   \frac{\partial L}{\partial x} = 2 + 2\lambda x = 0 \\
   \frac{\partial L}{\partial y} = -1 + 2\lambda y = 0 \\
   \frac{\partial L}{\partial z} = 2 + 2\lambda z = 0 \\
   \frac{\partial L}{\partial \lambda} = x^2 + y^2 + z^2 - 9 = 0
   \end{cases}$$

4. **Решение системы уравнений:**
   Выразим $x, y, z$ через $\lambda$: $x = -\frac{1}{\lambda}$, $y = \frac{1}{2\lambda}$, $z = -\frac{1}{\lambda}$.
   Подставим в ограничение:
   $$\left(-\frac{1}{\lambda}\right)^2 + \left(\frac{1}{2\lambda}\right)^2 + \left(-\frac{1}{\lambda}\right)^2 = 9 \implies \frac{9}{4\lambda^2} = 9 \implies \lambda = \pm \frac{1}{2}$$

   * При $\lambda = \frac{1}{2} \implies M_1(-2, 1, -2)$
   * При $\lambda = -\frac{1}{2} \implies M_2(2, -1, 2)$

5. **Определение характера точек:**
   * $f(M_1) = f(-2, 1, -2) = 2(-2) - 1 + 2(-2) = -9$ (Минимум)
   * $f(M_2) = f(2, -1, 2) = 2(2) - (-1) + 2(2) = 9$ (Максимум)

## 3. Код программы на Python (с использованием SymPy)

```python
import sympy as sp

# Объявление переменных
x, y, z, lmbda = sp.symbols('x y z lmbda')

# Целевая функция и ограничение
f = 2 * x - y + 2 * z
g = x**2 + y**2 + z**2 - 9

# Функция Лагранжа
L = f + lmbda * g

# Частные производные
eq1 = sp.Eq(sp.diff(L, x), 0)
eq2 = sp.Eq(sp.diff(L, y), 0)
eq3 = sp.Eq(sp.diff(L, z), 0)
eq4 = sp.Eq(sp.diff(L, lmbda), 0)

# Решение системы уравнений
solutions = sp.solve((eq1, eq2, eq3, eq4), (x, y, z, lmbda))

print("Найденные точки и значения функции:")
for sol in solutions:
  val = f.subs({x: sol[0], y: sol[1], z: sol[2]})
  print(f"Точка (x, y, z, lambda): {sol}")
  print(f"Значение функции f: {val}\n")
```
