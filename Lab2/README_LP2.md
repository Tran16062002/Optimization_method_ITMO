## 2. Теоретические сведения

### 2.1. Липшицева функция

Функция `f(x)` называется **липшицевой** на отрезке `[a, b]`, если
существует константа `L > 0` такая, что для любых `x₁, x₂ ∈ [a, b]`:

```text
|f(x₁) − f(x₂)| ≤ L·|x₁ − x₂|
```

Константа `L` называется **константой Липшица**. Геометрически это
означает, что график функции можно «зажать» между двумя прямыми с
угловым коэффициентом `L` (и `−L`).

### 2.2. Идея метода ломаных (Пиявского)

Метод Пиявского — детерминированный метод глобальной оптимизации.
Идея:

1. В испытанных точках `x₁, ..., xₙ` строим **миноранту** (нижнюю
   огибающую) с угловым коэффициентом `L`:

```text
φ(x) = max_i { f(xᵢ) − L·|x − xᵢ| }
```

Миноранта всюду лежит ниже графика `f(x)`.

2. Находим точку минимума миноранты — это следующая точка испытания.
На каждом интервале `[x₁, x₂]` миноранта — это максимум двух прямых:

```text
φ(x) = max( f₁ − L·(x − x₁), f₂ − L·(x₂ − x) )
```

Точка пересечения этих прямых:

```text
x_cross = (f₁ + L·x₁ − f₂ + L·x₂) / (2L)
```

3. Вычисляем `f(x_cross)` и добавляем точку в список вершин.

4. **Условие остановки:** `f(x_min) − φ(x_min) ≤ ε`, где `x_min` —
текущая лучшая точка, `φ(x_min)` — значение миноранты в этой точке.

### 2.3. Сходимость

Метод сходится к глобальному минимуму за конечное число итераций.
Оценка числа итераций:

```text
N ≈ O( L·(b − a) / ε )
```

То есть чем больше константа Липшица и чем меньше требуемая точность,
тем больше итераций.

## 7. Анализ результатов
### 7.1. Точность
Во всех тестах метод нашёл глобальный минимум с точностью ε,
несмотря на наличие нескольких локальных минимумов. Это ключевое
преимущество метода Пиявского перед градиентными методами.

### 7.2. Скорость сходимости
Растригин: 136 итераций при `ε = 0.01`, `L = 70`. Функция имеет
много локальных минимумов (по одному на каждый период `cos(2πx)`),
что заставляет метод «прощупывать» каждый из них.

Экли: 48 итераций при `L = 15`. Меньшая константа Липшица
обеспечивает более быструю сходимость.

`x + sin(πx)`: 62 итерации при `ε = 0.001`.

Двухъямная: 75 итераций при `ε = 0.001`. Метод корректно выбрал
более глубокий из двух локальных минимумов (`f(−1) = −0.3` против `f(1) ≈ 0.3`).

### 7.3. Влияние константы L
Если `L` занижена, миноранта может оказаться выше графика
функции, и метод может пропустить глобальный минимум — это ошибка.
Если `L` завышена, метод сходится, но медленнее (больше итераций).

Правило: `L ≥ max|f'(x)|` на отрезке `[a, b]`.

### 7.4. Влияние точности ε
Число итераций растёт как `O(1/ε)`. При `ε = 0.1` итераций примерно
в 10 раз меньше, чем при `ε = 0.01`.

### 7.5. Поведение кривых сходимости
Верхняя оценка (минимум f среди испытанных точек) монотонно
убывает и быстро приближается к истинному минимуму.

Нижняя оценка (минимум миноранты) монотонно возрастает.

Зазор между ними (серая область) сужается, и когда он становится
меньше `ε`, метод останавливается.
