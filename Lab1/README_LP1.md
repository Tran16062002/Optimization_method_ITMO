# Решение задачи линейного программирования

## 1. Постановка задачи

**Минимизировать**  
Z = x1 + 3*x2 + 2*x4 + x4

**при ограничениях:**
1. x1 + x2 + 2*x4 <= 8
2. x2 + x3 + x4  = 6
3. 2*x1 + x3     >= 2
4. x1, x2, x3, x4 >= 0

---

По условию практической работы необходимо:

1. привести задачу к каноническому виду;
2. сформулировать вспомогательную задачу;
3. решить вспомогательную задачу;
4. перейти к основной задаче;
5. решить основную задачу симплекс-методом;
6. записать оптимальную точку и значение целевой функции;
7. решить ту же задачу в Excel с помощью надстройки **Solver** и сравнить результаты.

---

## 2. Какие варианты / параметры используются?

### Шаг 1. Вариант математической задачи

Целевая функция:

```text
min Z = x1 + 3*x2 + 2*x3 + x4
```

Ограничения:

```text
x1 + x2 + 2*x4 <= 8
x2 + x3 + x4  = 6
2*x1 + x3     >= 2
x1, x2, x3, x4 >= 0
```

### Шаг 2. Переменные, добавленные при переходе к каноническому виду

Для первого ограничения:

```text
x1 + x2 + 2*x4 + x5 = 8
```

` x5 ` — дополнительная переменная.

Для второго ограничения:

```text
x2 + x3 + x4 + x7 = 6
```

` x7 ` — искусственная переменная.

Для третьего ограничения:

```text
2*x1 + x3 - x6 + x8 = 2
```

` x6 ` — избыточная переменная,  
` x8 ` — искусственная переменная.

Для поиска начального допустимого базиса используется **симплекс-метод**.

### Шаг 3. Вспомогательная задача:

```text
W = x7+x8 --> min
```

Если минммум равен `0`, искусственные переменные могут быть исключены и можно перейти к основной задаче.

### Шаг 4. Исходная задача является задачей минимизации

```text
min(Z).
```

## 5. Как решить задачу в Excel Solver

### Шаг 1. Создание таблицы, например:

| Переменная | Значение |
|---|---:|
| x1 | 0 |
| x2 | 0 |
| x3 | 0 |
| x4 | 0 |

Отдельно вычислите целевую функцию:

```text
Z=x1+3*x2+2*x3+x4.
```

Также создайте три ячейки для левых частей ограничений:

```text
C1 = x1 + x2 + 2*x4
C2 = x2 + x3 + x4
C3 = 2*x1 + x3
```

### Шаг 2. Включение Solver

Если пункта **Solver / Поиск решения** нет:

1. откройте **File → Options**;
2. выберите **Add-ins**;
3. внизу выберите **Excel Add-ins**;
4. нажмите **Go**;
5. установите флажок **Solver Add-in**;
6. нажмите **OK**.

После этого Solver будет доступен на вкладке **Data**.

### Шаг 3. Настройка Solver

В окне Solver:

1. Set Objective

Выберите ячейку с:

```text
Z=x1+3*x2+2*x3+x4.
```

Выберите:

```text
Min
```

2. By Changing Variable Cells

Выберите ячейки:

```text
x1, x2, x3, x4
```

3. Ограничения

Добавьте:

```text
x1 + x2 + 2*x4 <= 8
```

```text
x2 + x3 + x4 = 6
```

```text
2*x1 + x3 >= 2
```

Также установите:

```text
x1, x2, x3, x4 >= 0
```

4. Метод

В поле **Select a Solving Method** выберите:

```text
Simplex LP
```

После этого нажмите:

```text
Solve
```

### Шаг 4. Ответ

Ручное решение, Python и Excel Solver дают один и тот же результат:

```text
x1 = 0
x2 = 0
x3 = 2
x4 = 4

Z = 8
```
